You are continuing an existing Next.js 16 Pulse investment platform.

Project stack:
- Next.js 16 App Router
- React 19
- TypeScript

Project structure:
- app/page.tsx is the entry route.
- components/pulse/app.tsx owns the main shell and navigation.
- components/pulse/store.tsx owns current local fallback state.
- lib/pulse-data.ts contains fallback data.
- app/auth/callback/route.ts handles Supabase auth callback.
- lib/supabase/client.ts is the browser client.
- lib/supabase/server.ts is the server client.
- lib/supabase/proxy.ts refreshes sessions.
- app/api/admin/session/route.ts verifies approved admin users.
- app/api/cron/auto-close/route.ts processes matured holdings.
- vercel.json contains the cron schedule and headers.
