# Supabase Auth Hooks - Quick Setup (Copy-Paste Instructions)

## Which One to Choose?

### ✅ HTTPS (Recommended - Most Flexible)
Use this unless you have a specific reason not to.

### Postgres (Alternative - Database-only)
Use this if you want everything in the database.

---

## QUICK SETUP: HTTPS ENDPOINT (5 Minutes)

### Step 1: Add Environment Variable to Vercel

**In Vercel Dashboard:**
1. Go to your PULSE project
2. Click **Settings** (top right)
3. Go to **Environment Variables**
4. Click **Add New**

Add these:
```
SUPABASE_WEBHOOK_SECRET = (leave blank for now - Supabase generates it)
NEXT_PUBLIC_APP_URL = https://pulse-invest.vercel.app
RESEND_API_KEY = re_xxxxxxxxxxxx (or your email service key)
```

Save and **Redeploy** your project.

### Step 2: Create Auth Hook in Supabase

**In Supabase Dashboard:**

1. Go to **Authentication** (left sidebar)
2. Click **Hooks** (under Authentication menu)
3. Click **Add Send Email hook** (green button)

**Configure these settings:**

```
Hook type:        HTTPS
Endpoint URL:     https://pulse-invest.vercel.app/api/auth/hooks/send-email
```

Click **Create hook**

### Step 3: Copy Webhook Secret to Vercel

Supabase generates a `SUPABASE_WEBHOOK_SECRET` value after creating the hook.

1. Copy this value from Supabase
2. Go back to **Vercel → Settings → Environment Variables**
3. Update the `SUPABASE_WEBHOOK_SECRET` with the value
4. **Redeploy** your project

### Step 4: Choose Your Email Service

The handler supports Resend, SendGrid, or nodemailer.

**In `/app/api/auth/hooks/send-email/route.ts` (around line 180):**

Uncomment your email service section:

```typescript
// Example: Using Resend
const response = await resend.emails.send({
  from: 'noreply@pulse-invest.app',
  to,
  subject,
  html,
})
```

### Step 5: Test It

1. Go to `https://pulse-invest.vercel.app/auth/sign-up`
2. Sign up with any email
3. Check your email inbox
4. Click the verification link
5. You should land on `/auth/email-confirmed`

## QUICK SETUP: POSTGRES FUNCTION (10 Minutes)

### Step 1: Run SQL Migration

**In Supabase Dashboard:**

1. Go to **SQL Editor** (left sidebar)
2. Click **New Query**
3. Copy the entire content from: `/sql/auth-hooks-postgres-function.sql`
4. Paste it into the SQL editor
5. Click **Run**

This creates:
- `auth_email_logs` table (for audit)
- `handle_auth_email_hook()` function
- RLS policies

### Step 2: Create Auth Hook in Supabase

**In Supabase Dashboard:**

1. Go to **Authentication** → **Hooks**
2. Click **Add Send Email hook** (green button)

**Configure these settings:**

```
Hook type:            Postgres
Postgres Schema:      public
Postgres function:    handle_auth_email_hook
```

Click **Create hook**

### Step 3: Set Up Email Processing

Since Postgres can't send emails, you need a separate process.

**Option A: Simple HTTP endpoint (Recommended)**

Create `/app/api/cron/process-auth-emails/route.ts`:

```typescript
import { createClient } from '@/lib/supabase/server'

export async function GET() {
  const supabase = await createClient()
  
  const { data: logs } = await supabase
    .from('auth_email_logs')
    .select('*')
    .eq('status', 'pending')
    .limit(10)

  for (const log of logs || []) {
    try {
      // Call your email service here
      // await resend.emails.send(...)
      
      await supabase
        .from('auth_email_logs')
        .update({ status: 'sent' })
        .eq('id', log.id)
    } catch (error) {
      // Log error
    }
  }
  
  return Response.json({ success: true })
}
```

### Step 4: Test It

Same as HTTPS approach above.

## Environment Variables Checklist

### Required:

```bash
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
SUPABASE_WEBHOOK_SECRET=your_webhook_secret (generated by Supabase)

# App
NEXT_PUBLIC_APP_URL=https://pulse-invest.vercel.app

# Email Service (pick one)
RESEND_API_KEY=re_xxxxxxxxxxxx
# OR
SENDGRID_API_KEY=SG.xxxxxxxxxxxx
# OR
EMAIL_USER=your@gmail.com
EMAIL_PASSWORD=your_app_password
```

### How to Find/Generate These:

**SUPABASE_WEBHOOK_SECRET:**
- Supabase Dashboard → Authentication → Hooks → (after creating hook)

**RESEND_API_KEY:**
- Go to resend.com → API Keys → Create key

**SENDGRID_API_KEY:**
- Go to sendgrid.com → Settings → API Keys → Create new

## What Happens When User Signs Up

```
User fills form at /auth/sign-up
         ↓
Clicks "Sign Up"
         ↓
supabase.auth.signUp({ emailRedirectTo: '/auth/callback' })
         ↓
Supabase sends webhook to your HTTPS endpoint:
POST /api/auth/hooks/send-email
{
  "type": "signup",
  "user": {
    "email": "user@example.com",
    "confirmation_token": "abc123...",
    ...
  }
}
         ↓
Your handler receives event
         ↓
Generates beautiful email with verification link
         ↓
Calls Resend/SendGrid to send
         ↓
User receives email
         ↓
User clicks link: /auth/callback?token_hash=X&type=email
         ↓
Email is verified
         ↓
User lands on /auth/email-confirmed
         ↓
User can access dashboard
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Email not received | Check API key is valid, endpoint is public, webhook secret matches |
| "Invalid signature" error | Ensure SUPABASE_WEBHOOK_SECRET matches exactly (no spaces) |
| Verification link doesn't work | Check /auth/callback route exists and uses verifyOtp() |
| Redirect loop | Verify /auth/email-confirmed page exists |
| Template looks broken | Check HTML is valid, no special characters in variables |
